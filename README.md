# 幽灵之夜

一个给幼儿玩的、可离线安装到手机主屏幕的互动网页应用。

## 本地运行

在项目目录启动任意静态服务器，例如：

```powershell
python -m http.server 4173
```

然后用同一局域网内的手机访问电脑的局域网地址和端口 `4173`。

## 玩法

- 轻触幽灵：它会害羞捂脸。
- 拖动并松手：拉扯、抛出幽灵。
- 长按幽灵：充气后变出三只小幽灵。
- 双击夜空：召唤一只小幽灵。
- 月亮按钮：打开月光，光下的幽灵会害羞。
- 星星按钮：轮流触发星星雨、泡泡和大幽灵。
- 长按右下角齿轮：打开家长休息时间设置。

游戏不依赖网络、不含广告，也不收集数据。
